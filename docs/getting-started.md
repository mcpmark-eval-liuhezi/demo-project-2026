# Getting started with the demo project

This short guide walks you through cloning the project and getting it running on your machine for the first time. It is intentionally small so newcomers can go from zero to a working copy in a few minutes. If anything here is unclear or fails, please open an issue so we can fix it for the next person.

## Setting up locally

Start by cloning the repository and entering the directory. The project only requires Git and a recent version of your language runtime, so there is no heavy dependency chain to install first. Once cloned, run the setup step once to prepare your working directory, and you are ready to go.

## Running the project

After setup, the project can be started with a single command from the repository root. It runs entirely on your machine with no external services, which makes it easy to experiment safely. Stop it with Ctrl+C whenever you are finished, and restart it the same way whenever you need it again.
